# 归途项目地图定位功能使用说明文档

适用于：小组成员部署、演示、测试地图找寻与距离显示功能  
项目目录：`Journey-Home-main`  
核心页面：`http://localhost:5173/map`、`http://localhost:5173/animals`

## 一、功能概述

地图定位功能用于帮助用户根据当前位置查找附近的送养动物与救助站，并在送养列表中显示“距离我多远”。主要服务于线下救助、就近领养、附近资源查询等场景。

| 功能点 | 说明 | 用户入口 |
|---|---|---|
| 地图找寻 | 在地图上展示附近动物、救助站与当前位置相关信息 | `/map` 页面，或导航栏“地图找寻” |
| 一键查看周边 | 获取当前位置，查询一定范围内的动物和救助站 | 地图页面按钮 |
| 送养列表距离 | 动物卡片显示“距你 x km / m” | `/animals` 页面“显示距离”按钮 |
| 发布位置 | 发布送养信息时记录经纬度 | 发布 / 编辑动物信息页面 |
| 附近救助站 | 按当前位置计算并展示附近救助站距离 | 地图页面 |

> 使用前提：地图和距离计算依赖浏览器定位授权。第一次点击“显示距离”或“一键查看周边”时，需要在浏览器弹窗中选择“允许”。

## 二、普通成员使用方式

如果使用一键部署版压缩包：

1. 解压项目压缩包，不要直接在压缩包内运行。
2. 进入解压后的 `Journey-Home-main` 文件夹。
3. 双击 `一键启动项目.bat`。
4. 浏览器打开 `http://localhost:5173`。
5. 登录后进入“地图找寻”或“送养列表”验证功能。

常用地址：

| 页面 | 地址 | 作用 |
|---|---|---|
| 首页 | `http://localhost:5173` | 系统主界面 |
| 地图找寻 | `http://localhost:5173/map` | 查看附近动物、救助站、距离和地图标记 |
| 送养列表 | `http://localhost:5173/animals` | 查看送养动物卡片，并显示与自己的距离 |

## 三、地图找寻页面使用流程

1. 打开系统并登录账号。
2. 点击导航栏“地图找寻”，或访问 `http://localhost:5173/map`。
3. 点击“一键查看周边”。
4. 浏览器弹出定位权限时选择“允许”。
5. 系统获取当前经纬度，并调用后端附近查询接口。
6. 地图展示附近动物或救助站点位，列表中显示距离。

如果误点“拒绝”，需要在浏览器地址栏左侧的网站权限设置中重新允许定位，或者清除站点权限后刷新页面。

## 四、送养列表显示距离使用流程

1. 打开 `http://localhost:5173/animals`。
2. 点击页面上方“显示距离”按钮。
3. 首次使用时允许浏览器定位。
4. 动物卡片会显示距离信息。
5. 切换筛选条件或分页后，系统会继续使用已缓存的位置计算距离。

| 显示效果 | 含义 |
|---|---|
| 距你 850 m | 距离小于 1 公里 |
| 距你 2.3 km | 距离大于等于 1 公里 |
| 不显示距离 | 该动物没有经纬度，或用户没有授权定位 |

## 五、发布送养信息时如何保证能被计算距离

- 发布动物信息时，建议点击“使用当前位置”，让系统自动写入经纬度。
- 也可以填写地址后进行地址解析，但准确度取决于地图服务返回结果。
- 如果动物记录没有经纬度，系统无法计算距离，地图页面也可能不显示点位。
- 测试时建议先用一个账号发布带位置的动物，再用另一个账号查看地图和列表距离。

## 六、常见问题与处理办法

| 问题 | 可能原因 | 处理办法 |
|---|---|---|
| 地图空白或加载失败 | 高德地图 Key 没有正确读取、网络异常 | 检查配置、刷新页面、确认网络可访问地图服务 |
| 点击定位后没有反应 | 浏览器定位权限被拒绝 | 重新允许定位或清除站点权限 |
| 列表不显示距离 | 没点击“显示距离”、未授权定位、动物无经纬度 | 点击“显示距离”；允许定位；确认数据有经纬度 |
| 地图没有动物点位 | 数据库中无带坐标动物，或范围内无数据 | 先发布一条带位置的动物信息 |
| AI 助手未配置 | 智谱 AI Key 未写入后端配置 | 内置 Key 版本通常无需处理；失效后重新配置 |
| `localhost:5173` 无法访问 | 前端服务已关闭 | 重新运行前端或双击一键启动脚本 |
| 后端 8080 无法启动 | 端口被占用或旧服务未关闭 | 关闭旧后端窗口或结束 Java 进程 |

## 七、开发维护说明

| 类别 | 主要文件 / 接口 | 作用 |
|---|---|---|
| 前端页面 | `frontend/src/views/MapView.vue` | 地图找寻主页面 |
| 地图组件 | `frontend/src/components/GeoNearbyMap.vue` | 地图、点位、列表和定位交互 |
| 地图工具 | `frontend/src/utils/amap.js` | 加载高德地图、浏览器定位、地址解析 |
| 送养列表 | `frontend/src/views/AnimalsView.vue` | 动物卡片距离显示入口 |
| 前端 API | `frontend/src/api/index.js` | 封装附近动物、救助站、距离查询请求 |
| 动物定位接口 | `/api/animal/nearby` | 查询附近动物并返回距离 |
| 救助站接口 | `/api/rescue-station/nearby` | 查询附近救助站并返回距离 |
| 距离算法 | `backend/src/main/java/com/guitu/util/HaversineUtil.java` | Haversine 公式计算两点球面距离 |
| 实体字段 | `Animal / RescueStation / UserLocationHistory` | 保存经纬度和定位历史 |

## 八、验收测试清单

1. 启动项目后访问 `http://localhost:5173`，系统首页正常打开。
2. 进入 `/map` 页面，地图页面正常显示。
3. 点击“一键查看周边”并允许定位，页面显示当前位置。
4. 发布一条带当前位置的动物信息。
5. 返回 `/map` 查看，该动物显示在地图或附近列表中。
6. 进入 `/animals` 点击“显示距离”，动物卡片显示“距你 x km / m”。
7. 切换筛选或刷新页面，距离功能仍可正常显示或重新点击后显示。

## 九、安全与协作注意事项

- 一键部署内置 Key 版仅用于小组内部演示和课程设计提交，不建议上传到公开 GitHub、Gitee 或论坛。
- 如果 API Key 泄露或调用异常，应及时到对应开放平台禁用旧 Key 并重新生成。
- 提交公开仓库时，应删除真实 Key，改用 `.env.example` 或环境变量占位方式。
- 地图定位结果受浏览器、网络、系统定位服务影响，演示时优先使用 Chrome 或 Edge。
