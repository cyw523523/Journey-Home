# 地图定位功能迁移说明

本版本已把之前的“地理位置和地图展示”功能迁移到 `Journey-Home-main` 项目中。

## 已迁移内容

- 前端地图页面：`frontend/src/views/MapView.vue`
- 前端地图组件：`frontend/src/components/GeoNearbyMap.vue`
- 高德地图加载与浏览器定位工具：`frontend/src/utils/amap.js`
- 前端路由：`/map`
- 顶部导航入口：登录后显示“地图找寻”
- 动物发布表单：支持填写发现地经纬度和“使用当前位置”
- 后端动物位置接口：`/api/animal/location`、`/api/animal/nearby`
- 后端救助站位置接口：`/api/rescue-station/location`、`/api/rescue-station/nearby`
- 地图聚合接口：`/api/map/points`、`/api/map/around`、`/api/map/animals/nearby`、`/api/map/stations/nearby`
- 经纬度字段：动物表与救助站表均增加 `location_lng`、`location_lat`
- 距离计算工具：Haversine 球面距离算法

## 运行前配置

复制前端示例配置：

```powershell
cd frontend
copy .env.example .env.local
```

然后在 `.env.local` 里填入自己的高德地图 Key：

```env
VITE_AMAP_KEY=你的高德Web端JS API Key
VITE_AMAP_SECURITY_CODE=你的高德安全密钥
```


```text
http://localhost:5173/map
```

## 数据库说明

项目默认 `spring.jpa.hibernate.ddl-auto=update`，后端启动时一般会自动补齐新增字段。
如果你的数据库没有自动更新，可手动执行：

```text
scripts/map_location_update.sql
```
